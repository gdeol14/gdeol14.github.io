★ Credited Security Research · WAS705

BookStack Vulnerability Research — 3 Credited HIGH Severity Findings

Independently discovered and responsibly disclosed three HIGH severity vulnerabilities in BookStack, an open-source documentation platform with 18K+ GitHub stars. Credited by name in all three official security releases by maintainer Dan Brown. Each finding bypassed the patch written for the previous one — demonstrating deep understanding of HTMLPurifier sanitizer internals and the fundamental fragility of blocklist-based content filtering.

Burp Suite ProPHPHTMLPurifierLaravelResponderSource Code ReviewResponsible Disclosure
  • Finding 1 (v26.05.1): file:// protocol injection in content attributes enabling NTLM credential theft on Windows
  • Finding 2 (v26.05.2): file:// protocol bypass via srcset attribute — not covered by v26.05.1 patch due to HTMLPurifier treating srcset as "URI candidate list"
  • Finding 3 (v26.05.2): Protocol-relative URL bypass (//attacker) in srcset — bypasses str_contains() blocklist. Three vectors: credential phishing, silent SMB hash theft, session cookie leakage
  • All three confirmed via Burp Suite Pro, Responder (NTLMv2 capture), and source code review of SrcsetAttrDef.php and ExportFormatter.php
  • Responsible disclosure to Dan Brown — credited by name in all three official security release blog posts
  • Comprehensive STRIDE threat model with 12 threats mapped to 13 BookStack components based on source code analysis
